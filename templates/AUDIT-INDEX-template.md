# AUDIT-INDEX template

Make a new document in your project folder titled "AUDIT-INDEX". Copy everything inside the box below into it, then delete the fictional example (the "Example (fictional):" line and the OWN-20270115-01 line under it), so that no made-up tag is left in your index. Each new line goes at the end.

```text
AUDIT-INDEX

One line per Owner decision or Owner-directed edit (rule 11). Lines are only added, never rewritten. A mistake is fixed by adding a correction line that names the line it corrects. Search the folder for "OWN-" to find every use of the Owner's authority.

Line format:
OWN-YYYYMMDD-NN | [DECISION / DIRECTED-EDIT / DIRECTED-ACTION / DELEGATED DECISION] | [date and time]: Owner said "[exact words]" to [what was proposed]. [What was decided or done] | Logs: [log title] | Files edited: [file titles] | Restore: version history, [time]; revisions before the edit: [file] [revision ID]
```
